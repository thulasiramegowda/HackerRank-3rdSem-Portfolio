# Compare the Triplets

## Problem

Compare the corresponding ratings of Alice and Bob and calculate their individual scores.

## Approach

Each of the three elements is compared with the corresponding element of the other array.

Alice receives one point when her value is greater, while Bob receives one point when his value is greater. Equal values do not give a point to either person.

## Complexity Analysis

- Time Complexity: O(1)
- Space Complexity: O(1)

Only three values are compared, so the amount of work remains constant.
